## 🌐 Instant Deployment

### Option A: GitHub Pages
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "feat: launch Priyadharshini cinematic portfolio"
   git remote add origin https://github.com/Priyadharshini3-pri/portfolio.git
   git push -u origin main
   ```
2. Go to repository **Settings** → **Pages** → Select `main` branch → **Save**.

### Option B: Vercel
Run `vercel` or link your GitHub repo on [vercel.com](https://vercel.com). Deploys in under 15 seconds.

### Option C: Netlify
Drag and drop the folder directly into the [Netlify Drop](https://app.netlify.com/drop) dashboard.
